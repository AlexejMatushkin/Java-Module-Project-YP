**Проектная работа №1.**

**Программа "Гонка автомобилей" или "«24 часа Ле-Мана»"**

Простая консольная программа для определения победителя гонки на основе скорости машин.

**Описание**

Программа запрашивает у пользователя данные о 3 автомобилях (название и скорость), затем вычисляет,
какая машина проедет наибольшую дистанцию за 24 часа, и выводит победителя.

**Улучшение**

Проверка корректности названия машины:<br>
- Название не может быть пустым<br>
- Максимальная длина названия - 20 символов<br>
- Допустимы только буквы (русские/английские), цифры и пробелы

Улучшенный ввод скорости:<br>
- Добавлена обработка нечислового ввода<br>
- Более информативные сообщения об ошибках

Технические улучшения:<br>
- Улучшенная обработка ошибок пользовательского ввода
- Чистый и понятный код проверок

**Как запустить**

1.Перейти в папку Main.java.<br>
2.Нажать на кнопку "Run".<br>
3.Введите данные в консоль(название и скорость трёх автомобилей).
